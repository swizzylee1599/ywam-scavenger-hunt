# YWAM Siem Reap Scavenger Hunt

Mobile-first scavenger hunt web app for the YWAM National Staff Conference.

## Current MVP
- Registration by name + YWAM base
- Automatic team assignment
- Challenge list with points
- Photo/video submissions
- Live leaderboard
- Live activity feed
- Confetti feedback

## Deploy
Import this repository into Vercel as a static site. No build command is needed.
